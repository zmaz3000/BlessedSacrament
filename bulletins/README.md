# Bulletin Upload Workflow

1. Upload this week's PDF as `latest.pdf` in this `bulletins` folder.
2. Move the previous `latest.pdf` into `bulletins/archive/` and rename it with date, for example:
   - `2026-04-27-bulletin.pdf`
3. Update archive links in `bulletin.html` as needed.

Current live bulletin link used by site:

- `/bulletins/latest.pdf`
